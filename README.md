# MoneyTracker — Telegram-бот учёта трат

Принимает фото чеков (с подписью или без), распознаёт трату через **Gemini (vision)**,
умно категоризирует и записывает в Excel с итогами по валютам и категориям.
Бот личный — доступ только у владельца (см. «Доступ»).

## Возможности
- 📸 Фото чека → сумма, валюта, дата, описание, категория автоматически.
- ✍️ Текст без фото («Ресторан Plov 4500 тенге») тоже работает.
- 🍽 Рестораны записываются как `Ресторан «Название»` без перечисления блюд.
- ✏️ Под каждой тратой — кнопки категории, правки суммы/описания и удаления.
- 💱 Валюты: тенге (KZT), сом (KGS), доллар (USD). Конвертация в USD по живому курсу.
- 💼 Кошелёк: остаток по валютам, пополнения (`/add`) и обмены.
- 📂 Профили учёта — у каждого свой лист и кошелёк.
- 📊 Лист «Итоги»: суммы по каждой валюте, общая в USD, суммы по категориям.
- 📊 `/total` — текстовая сводка; период: `/total месяц`, `/total неделя`, `/total 7`.
- 📤 `/excel` и `/csv` — выгрузка трат файлом.
- 💱 Проверка обменника: «конвертация 30 долларов 15000 тенге» (отдал → получил) — сравнение с рыночным курсом.

## Команды и сообщения
- `/start`, `/help` — инструкция.
- `/total [период]` — сводка (без аргумента — за всё время; `сегодня`/`неделя`/`месяц`/`год`/`N` дней).
- `/wallet`, `/add 5000 USD` — кошелёк и пополнение.
- `/profiles` — переключить/создать профиль.
- `/excel`, `/csv` — выгрузка таблицы.
- `конвертация <отдал> <получил>` — проверка курса обменника, напр. «конвертация 30 долларов 15000 тенге».
- `конвертация <сумма>` — пересчёт одной суммы в другие валюты по рынку.

## Доступ
Бот отвечает только владельцу. По умолчанию **первый написавший после запуска
становится владельцем** (auto-claim, id хранится в `settings.json`). Чтобы задать
явно, впиши в `.env`: `ALLOWED_USER_IDS=123456789` (свой Telegram-id, напр. от @userinfobot;
можно несколько через запятую).

## Автозапуск (чтобы не запускать вручную)
После того как вписаны ключи в `.env`, выполни один раз:

```bash
./install_autostart.sh
```

Бот будет работать в фоне и стартовать при входе в систему (macOS LaunchAgent).
Логи — в `bot.log`. Остановить: `launchctl unload ~/Library/LaunchAgents/com.moneytracker.bot.plist`.

## Настройка
Открой `.env` (пример — в `.env.example`) и впиши ключи:

```
TELEGRAM_BOT_TOKEN=...
GEMINI_API_KEY=...
GEMINI_MODEL=gemini-2.5-flash
EXCEL_PATH=expenses.xlsx
# ALLOWED_USER_IDS=123456789   # необязательно: явный список владельцев
```

## Запуск

```bash
source .venv/bin/activate
python bot.py
```

Затем напиши боту в Telegram `/start` и пришли фото чека.

## Структура
- `bot.py` — Telegram-бот и обработчики.
- `receipt_analyzer.py` — распознавание чека через Gemini (vision).
- `excel_store.py` — запись в Excel, итоги, кошелёк, стабильные ID трат.
- `currency.py` — курсы валют и конвертация в USD.
- `settings.py` — валюта по умолчанию, профили, владелец.
- `config.py` — конфигурация из `.env`.

Excel-файл создаётся автоматически при первой трате. Подробный контекст для
разработки — в `AGENT.md`.
